# 无浪潮 No Wave · UI_DESIGN_SYSTEM.md

> 版本 0.2（概念阶段）。依据首页设计图、`nowave-home-demo`、`/post` `/editor` 设计图，以及文学平台六个核心页面设计稿整理。
> **产品定位（v0.2 起）：** 严肃文学发表与交流平台。页面以“作品”而非“功能卡片”为中心。
> **已确认：** 视觉方向、色板、字体组合、首页结构、左侧竖脊、导航条、默认封面机制。
> **设计假设（需与源码核对）：** `/post`、`/editor`、`/chat` 的版式、通知与关注的数据模型、路由与组件命名。

## 0. 怎么用这份文档

新页面开工前按顺序检查：**① 用 token，不写裸色值 → ② 套用页面骨架（§7） → ③ 只用 §4 里的组件，缺了先补进来 → ④ 动效与 WebGL 遵守 §6 的预算 → ⑤ 过一遍 §9 清单。**

## 1. 设计原则

1. **一页一个主角。** 每个页面只有一个视觉焦点（首页是首屏画面，文章页是标题与封面，编辑器是正文）。其余让位。
2. **文字少，留白多。** 界面不放解释性段落；标签、编号、日期足够。
3. **粗粝与精确并存。** 图像可以涂抹、扭曲；排版、网格、对齐必须精确。两者对撞，不要混淆。
4. **没有装饰性容器。** 不用阴影、渐变、玻璃拟态、圆角卡片。层级靠字号、留白、1px 细线、整块色面。
5. **功能入口永远清楚。** 竖脊、导航条、搜索、通知在每个页面位置不变。
6. **中文优先。** 简体中文（`zh-CN`）为基准，英文（`en`）同时验证。

| 项 | 值 |
|---|---|
| 中文名 | 无浪潮 |
| 英文名 | No Wave |

## 3. Tokens

### 3.1 颜色

```css
:root{
  --paper:#F2EEE6;  --ink:#0F0D0C;           /* 页面底 / 主文字 */
  --orange:#D8541F; --red:#8B1A10;           /* 强调 / 深强调 */
  --flesh:#E9A98F;                           /* 仅用于图像与插画 */
  --text-2:#5E5850;                          /* 次级文字，对 paper 6.1:1 */
  --text-2-on-ink:#B5AEA3;                   /* 黑底次级文字，对 ink 8.7:1 */
  --line:var(--ink);                         /* 1px 分隔线 */
  --rail:#0F0D0C;  --on-image:#F2EEE6;       /* 竖脊与图上文字：不随主题反转 */
}
@media (prefers-color-scheme:dark){
  :root:not([data-theme="light"]){--paper:#0F0D0C;--ink:#F2EEE6;--text-2:#B5AEA3}
}
:root[data-theme="dark"]{--paper:#0F0D0C;--ink:#F2EEE6;--text-2:#B5AEA3}
```

| 语义 | 值 | 用法 |
|---|---|---|
| `color.action.primary` | `--orange` 底 + `#0F0D0C` 字（4.7:1） | 主按钮、角标 |
| `color.action.secondary` | `--ink` 底 + `--paper` 字（16.5:1） | 次按钮、提示条 |
| `color.link.hover` | `--orange` | 仅用于 ≥ 24px 或 ≥ 18.66px 粗体（对 paper 仅 3.5:1） |
| `color.text.accent-small` | `--red` | 小字需要强调色时（对 paper 8.0:1） |
| `color.focus` | `--orange`，3px 实线，外偏 3px | 所有可聚焦元素 |
| 语义色 | 成功 `#2F6B3A`、警告 `#8A5A00`、错误 `--red`、提示 `--ink` | 必须配图标或文字，不能只靠颜色 |

> 成功与警告色是占位建议，落地时需要对 paper 与 ink 各验证一次对比度。

### 3.2 字体

```css
--font-serif-display: 'Instrument Serif','Noto Serif SC',serif;   /* 拉丁展示 */
--font-zh-serif:      'Noto Serif SC','Instrument Serif',serif;   /* 中文标题/正文 */
--font-sans:          'Inter Tight','Noto Sans SC',sans-serif;    /* UI、数字、标签 */
```

| 角色 | zh-CN | en | 备注 |
|---|---|---|---|
| Display 字标 | 340px / lh 0.8 / −0.04em | 同 | 仅首屏、页尾 |
| H1 页面标题 | Noto Serif SC 600，clamp(40,6vw,96) / 1.1 | Instrument Serif 400，同字号 ×1.1 | 英文衬线偏小，需放大约 10% |
| H2 区块标题 | 56px / 1.1，中文 600 + 拉丁斜体并排 | 同 | 如“精选 *Selected*” |
| Title 条目标题 | Noto Serif SC 600，20–28px / 1.45，`text-wrap:balance` | Instrument Serif 28–36px / 1.2 | 最多 2 行（列表）/ 3 行（卡片） |
| Body 正文 | Noto Serif SC 400，18px / 1.9，行宽 ≤ 32 字 | Instrument Serif 21px / 1.6 或 Inter Tight 17px / 1.65，行宽 ≤ 68 字符 | 文章页专用 |
| UI 文字 | Noto Sans SC 500，15px / 1.5 | Inter Tight 500，15px / 1.5 | 导航、按钮 |
| Meta 元数据 | Inter Tight 400，13px / 1.5，+0.02em，等宽数字 | 同 | 不小于 12px，不用细字重 |
| Mono 标注 | 竖脊：13px / 700 / +0.24em | 同 | 全站只有竖脊使用大字距 |

规则：中文大字不加负字距（最多 −0.01em），拉丁大字可加到 −0.04em；中文标题字重 ≤ 600，主题大字（≥ 120px）用 500；字体加载用 `font-display: swap`，并保留 PingFang SC / Microsoft YaHei 回退。

### 3.3 间距、圆角、边框

- 间距基准 4px：`space.1=4, 2=8, 3=12, 4=16, 6=24, 8=32, 10=40, 14=56, 20=80, 30=120`。
- 页面边距：桌面 80px，≥ 1024 以下 40px，移动 16px。内容最大宽度 1280px。
- 区块上下留白：桌面 120–140px，移动 64–80px。
- 圆角：**默认 0**。仅允许 `999px` 用于导航条与角标。
- 边框：1px 实线 `--line`；强分隔 3px。**不使用阴影。**

### 3.4 动效

| Token | 值 |
|---|---|
| `motion.fast` | 150ms，`cubic-bezier(.2,0,0,1)` |
| `motion.base` | 300ms，同上 |
| `motion.enter` | 900–1100ms，`power3.out` / `power4.out` |
| `motion.page` | 载入幕布 900ms，`power4.inOut` |

### 3.5 断点

`1440`（设计基准）/ `1024` / `768`（导航与竖脊切换点）/ `390` / `320`。

## 4. 组件

### 4.1 竖脊 Rail

48px 宽、黑底、全高、固定在左侧。内容是竖排的 `无浪潮 · No Wave — YYYY.MM`，是首页链接（`aria-label="无浪潮 No Wave 首页"`）。< 768px 隐藏，由顶栏“选单”代替。所有页面一致，**不得移除**。

### 4.2 导航条 Pill

固定右上，纸色底（`--paper`）、无边框、`999px` 圆角，高 52px。顺序固定：`精选 · Blog · 主题 │ 简 / EN │ 搜索 │ 铃铛`。当前页用下划线或粗体，不靠颜色。< 768px 收成 `搜索 · 铃铛 · 选单`。

### 4.3 铃铛与通知面板

- 铃铛按钮 44×44，右上角角标：橙底黑字、`min-width:16px`、数字 1–99，超出显示 `99+`。无未读时不显示角标。
- `aria-label="通知，N 条未读"`，面板用 `aria-expanded` 控制。
- 面板（桌面 360px 宽，移动全宽）：行式列表，每行 `类型图标 + 一行摘要 + 时间`；“全部标为已读”置于面板头部；空状态一行字 + 一个动作。
- 通知类型（待核实）：`follow.new`（有人关注你）、`post.new`（关注的作者/主题发文）、`comment.new`、`message.new`。同一组件，不同图标。

### 4.4 按钮

| 变体 | 样式 | 用法 |
|---|---|---|
| Primary | 橙底、黑字、高 52、内边距 0 28、直角 | 每屏最多 1 个 |
| Secondary | 黑底、纸色字 | 页内次要动作 |
| Text-arrow | 文字 + `→`，上方 1px 线 | “全部文章”类入口 |
| Icon | 44×44，无底 | 搜索、铃铛 |

状态：hover 反色或变橙；focus 3px 橙环；disabled 50% 不透明度 + `aria-disabled`；loading 文字改为“处理中…”并禁用，不使用转圈。

### 4.5 图片说明 Caption

`编号·分类（Meta）→ 标题（Title）→ 日期（Meta）`，图片与文字间距 16px。hover 标题变橙。

### 4.6 索引行 Row

`56px 编号 | 标题 + Meta`，上方 1px 线，行内上下 28px。是最新、搜索结果、相关文章、会话列表共用的基础行。hover 整行不变色，只让标题变橙（桌面 Demo 里最新区会联动左侧大图）。

### 4.7 跑马灯带 Band

黑底窄带，高 72px，交替无衬线粗体与衬线斜体。速度随滚动速度变化，向上滚时反向。**装饰性**，`aria-hidden`，每页最多 1–2 条。

### 4.8 主题大字

纯文字链接，168px，500 字重，后缀橙色小编号。hover 变橙。

### 4.9 表单

输入框：高 52、1px 线、直角、透明底；标签在上方 13px Meta；错误：红色文字 + `⚠` 文本前缀“错误：”，并用 `aria-describedby` 关联；成功：文字提示，不只变绿。

### 4.10 系统状态

- **空状态：** 一行大号衬线标题 + 一个文字箭头动作，不放插画。
- **错误页：** 巨大的 `404` 或 `500`（Display 字号，衬线斜体），下方一行说明 + 返回首页。
- **加载：** 页面首次载入用幕布计数（见 §6）；局部加载用 Meta 文字“载入中…”。
- **提示条 Toast：** 黑底纸字，直角，固定在底部居中，5 秒自动消失，可手动关闭。

### 4.11 图像与默认封面

- 封面比例：`4:5`（主）、`1:1`、`3:4`、`16:10`（宽幅）。`object-fit:cover`，按 `coverImage.focalPoint` 定位。
- **无封面时**：用 `sha256(post.id) % 4` 选择 `cover-ember / oxblood / bone / night` 之一，保证同一篇文章始终是同一张。
- 默认封面是装饰图，`alt=""`；真实封面必须有 alt。
- 需要更多变体用 `generate_cover.py --post-id <id>`，同一个 id 永远生成同一张。
- 图上文字必须放在纯色块（黑或纸色）里，**不要直接压在涂抹图上写小字**。

## 5. 版面骨架

```
┌─48─┬──────────────────────────── 1440 ───────────────────────────┐
│Rail│  内容容器 max 1280，左右边距 80                    [导航条] │
│    │  12 栏，栏距 24                                              │
└────┴──────────────────────────────────────────────────────────────┘
```

- 内容永远左对齐；用**错位**（上下偏移 60–160px、宽度 500/360/240）制造节奏，不用等宽网格。
- 整页只有一个“巨型字”区块（首屏），其余页面标题用 H1/H2，避免全站都喊叫。

## 6. 动效与 WebGL 规范

- **库：** GSAP 3.13 + ScrollTrigger + ScrollSmoother（`smooth: 1.2`）。固定元素（竖脊、导航条、面板）必须放在 `#smooth-wrapper` 之外。
- **允许的动效：** 载入幕布、字标入场、图片遮罩进入、视差（`data-speed`）、滚动速度驱动跑马灯、区块进入。**每个区块最多两种**。
- **WebGL：** 只用于**首屏的一张图**（涂抹/位移着色器）。要求：单 canvas、DPR ≤ 2、首屏离开视口后停止渲染、WebGL 不可用时回退为静态 `<img>`。其他页面（`/post`、`/editor`、`/chat`）**不使用 WebGL**，保证阅读与输入的稳定。
- **Canvas 2D：** 仅用于全局颗粒层（半分辨率、约 8fps、`pointer-events:none`、不超过 7% 不透明度）。
- **减少动态效果：** `prefers-reduced-motion` 时不启用平滑滚动、不跑马灯、不播放载入幕布、WebGL 只渲染一帧清晰画面。
- **性能底线：** 首屏 LCP 图 ≤ 800KB；滚动时主线程长任务 < 50ms；移动端关闭鼠标交互着色。

## 7. 页面骨架

### 7.1 首页 `/`（已设计）

首屏（全幅图 + 字标 + 精选条）→ 精选三联（错位）→ 跑马灯带 → 最新（左图右索引）→ 主题大字 → 页尾。

### 7.2 文章页 `/post/:slug`（假设）

- **阅读优先，无 WebGL。** 顶部 3px 橙色阅读进度线（固定）。
- 头部：分类 Meta → H1（≤ 3 行，`text-wrap:balance`）→ 副标题（Title 规格）→ 作者与日期一行 → 宽幅封面（16:10，轻视差，≤ 8% 位移）。
- 正文：单栏 680px，居中，Body 规格；标题 H2 用 Noto Serif SC 600；引用块用 3px 左侧黑线 + 衬线斜体；代码块黑底纸字，横向滚动；正文图可突破到 960px。
- 右侧目录（≥ 1280px）：Meta 字号，当前章节加粗并带橙色短线，不只靠颜色。
- 文末：作者块（头像 64px，**直角**，不用圆形）→ 关注按钮 → 相关文章（索引行 × 3）→ 评论。
- 关注：Secondary 按钮，状态 `关注 / 已关注`，已关注时文字变化 + 对勾，不只变色。

### 7.3 编辑器 `/editor`（假设）

- 三栏：竖脊 | 写作区（居中 720px，Body 规格，纸底）| 检查面板（320px，可收起）。
- 顶部细栏（56px，黑底）：左 `草稿 · 已保存 12:08`（Meta），右 `预览` `发布`（Primary）。保存状态用文字：`保存中…` / `已保存` / `保存失败，重试`。
- 封面选择：上传 / 从默认封面中选 / 自动（默认）。展示 4 张默认封面的缩略图，选中项有 3px 橙色框 + “已选”文字。
- 格式工具：选中文字时出现的黑色浮条（直角），按钮 44px。不使用侧边工具栏。
- 无 WebGL、无跑马灯、无视差；动效只留 `motion.fast`。

### 7.4 聊天 `/chat`（假设）

- 双栏：会话列表（360px，索引行规格，未读用橙色角标 + 数字）| 当前会话。< 768px 变成列表 → 详情的两级导航，顶部有“返回”文字按钮。
- 消息：**直角块**，己方黑底纸字，对方纸底 + 1px 线；不用气泡尾巴。时间戳用 Meta，按 5 分钟合并。同一发送者连续消息间距 4px，换人 16px。
- 输入区：固定底部，高 ≥ 56px，Primary 发送按钮；发送状态文字：`发送中 / 已发送 / 失败，重试`。
- 空会话：一行衬线大标题“还没有消息” + 文字箭头“去找人聊聊”。
- 无 WebGL；通知红点与铃铛共用同一未读数来源。

### 7.5 其他

`/search`（输入框 + 索引行结果 + 空状态）、`/topic/:slug`（H1 + 描述 + 索引行）、`/author/:id`（头像 + 简介 + 关注 + 文章索引）、`/notifications`（与铃铛面板同一行规格的整页版）、`404/500`。

## 8. 国际化

- 默认 `zh-CN`，同时验证 `en`；`lang` 属性随页面语言变化。
- 容器一律自适应高度，不固定标题高度；按钮用 `min-height` + `padding`，不用固定宽度。
- 英文导航比中文宽约 30–60%：导航条允许在 ≥ 1024 时换行为两组，< 1024 收起。
- 语言切换：优先跳转到同一文章的对应语言版本；不存在时留在原页，显示 Toast “此内容暂无英文版”，并给出该语言列表页入口。
- 日期：zh-CN `2026年10月1日`，en `Oct 1, 2026`；列表里的紧凑格式统一 `2026.10.01`。

- [ ] 状态不只靠颜色（未读数字、已关注文字、保存状态文字）。
- [ ] 竖脊、导航条在该页位置与首页完全一致。
- [ ] 本页只有一个视觉主角，没有阴影、渐变、圆角卡片。
- [ ] 长标题（中文 40 字、英文 20 个单词）、超长英文单词、缺失封面都已测试。

# v0.2 增补：文学平台页面规范

> 对应设计稿（均为设计占位数据，不是真实平台内容）：`01-read` 阅读页、`02-author` 作者主页、`03-discover` 发现页、`04-discussion` 作品讨论页、`05-submit` 作者投稿页、`06-search` 搜索结果页。

## 11. 信息架构与导航

主导航（导航条内，顺序固定）：`作品 · 作者 · 讨论 · 投稿 │ 简 / EN │ 搜索 │ 铃铛`。英文：`Works · Authors · Discussions · Submit`。
> 与首页设计图里的 `精选 · Blog · 主题` 不同。落地时首页导航需要同步改为本节标签（待你确认）。

| 路由（假设） | 页面 | 备注 |
|---|---|---|
| `/works` | 发现 / 作品目录 | 类型标签、筛选、排序、分页 |
| `/works/:slug` | 作品阅读页 | 版式随作品类型变化 |
| `/works/:slug/discussion` | 作品讨论页 | 作者回应 / 精读 / 短评三层 |
| `/authors/:id` | 作者主页 | 简介、代表作、全部作品、相关讨论 |
| `/submit` | 投稿 / 发布 | 写作、发布设置、预览、提交审核 |
| `/search?q=` | 搜索结果 | 作品 / 作者 / 类型三类结果 |

作品类型（8 种，中英对应）：小说 Fiction · 短篇小说 Short story · 诗歌 Poetry · 随笔 Essay · 评论 Review · 文学评论 Criticism · 非虚构 Nonfiction · 连载 Serial。类型标签是 1px 直角框，不做类型配色，保持单一强调色。

## 12. 排版：按作品类型区分版式

| 类型 | 正文 | 栏宽 | 特点 |
|---|---|---|---|
| 小说 / 短篇 / 随笔 / 评论 / 非虚构 | Noto Serif SC 400，`--fs` 19px / 行高 2.0，**首行缩进 2em** | 640px（约 31 字） | 段间距 1.4em；段末可有右侧批注标记 |
| 诗歌 | 22px / 行高 2.2，**不缩进，保留断行与缩进** | 520px | 节间距 2em；`white-space: pre-wrap`；标题可放大到 128px |
| 连载 | 同小说 + 章标题 28px 700 | 640px + 右侧章节目录 240px | 章节目录标注“已读 / 当前 / 未发布”（文字，不只靠颜色） |

阅读设置（阅读页内置）：字号 16–24px（每次 ±2px，默认 19）、纸色 / 墨色背景切换；用 `aria-pressed` 表示状态，操作后用 Toast 反馈“正文字号 21px”。字体、字号与行距任何情况下不低于上述值。

## 13. 新增组件

### 13.1 作品行 Work Row（发现、作者主页、搜索、相关推荐共用）

结构：`编号(56px) | 类型标签 · 日期 → 标题(28px/1.4, 最多 2 行) → 作者 · 篇幅 → 摘要(16px 衬线, 最多 2 行) | 封面(120×150, 可选)`。上方 1px 线，行内上下 28px。hover 只让标题变橙。< 768px：编号列缩为 36px，封面隐藏，标题 22px。
摘要用来判断“要不要读”，**不是**导语全文；诗歌摘要只取前两行。

### 13.2 类型标签条 Genre Tabs

横向文字标签，当前项 700 + 3px 橙色下划线，右上角小字显示数量。移动端横向滚动，不折行。键盘：`role="tablist"`，左右方向键切换（落地时实现）。

### 13.3 讨论三层（作品讨论页）

| 层级 | 视觉 | 规则 |
|---|---|---|
| 作者回应 | **整块黑底**、26px 衬线、置顶 | 一条回应只对应一个段落或一篇精读；标注“回应 §N” |
| 精读 Close reading | 左侧大号斜体段号 `§6` + 引用原文（3px 橙色左线）+ 标题 32px + 正文 18px/2.0，默认折叠到两段 | 建议 300 字以上并引用原文；可被编辑“编辑精选”；有字数标注 |
| 短评 Reply | 15–16px 无衬线，无头像，仅 `名字 · 时间` | 最多 280 字；超过提示改用精读 |

**不做**：无限信息流、头像墙、等级徽章、点赞排行。排序仅提供：精选 / 最新 / 最多回应。
发表流程：校验（空内容、超长）→ 按钮变“发送中…”→ 成功 Toast 并出现在列表顶部 → 失败显示“错误：…”并保留已输入内容。

### 13.4 作者头部（作者主页）

左 4 栏 sticky：头像占位（4:5）、笔名 104px、一行统计、简介（18px 衬线 / 行高 1.95）、操作区；右 8 栏：代表作品（3 条大行，标题 48px）→ 全部作品目录（按类型筛选，紧凑行：`日期 | 标题 | 类型 | 篇幅`）→ 围绕作品的讨论。
关注按钮：`+ 关注`（橙）→ `✓ 已关注`（黑），`aria-pressed`；“提醒我新作”是独立开关。

### 13.5 投稿步骤栏（`/submit`、`/editor` 共用）

黑色粘性栏：`1 写作 · 2 发布设置 · 3 预览`（Tab）+ 保存状态文字 + `保存草稿` + `提交审核`（Primary）。右侧留出导航条位置（桌面 580px）。保存状态文字：`保存中…` / `草稿 · 已保存 HH:MM` / `保存失败，重试` / `审核中 · 预计 2 个工作日`。保存失败同时出现橙色横幅，不依赖颜色单独表达。
提交前检查：标题、正文 ≥ 100 字、摘要、版权；未完成时对话框列出缺项并禁用“确认提交”。对话框用原生 `<dialog>`，关闭后焦点回到触发按钮。

### 13.6 搜索

大号输入框（`clamp(40px, 7cqw, 96px)` 衬线，下方 3px 线，聚焦线变橙）。聚焦时下拉“最近搜索”（`role="listbox"`）。类型筛选为按钮组；结果分“作品 / 作者 / 类型”三个 Tab，并带数量。命中词用 `mark`（橙底黑字）高亮，只在标题与摘要里高亮。

### 13.7 设计评审控制条（仅设计稿）

固定在页面底部的黑色条：视图（桌面 / 移动）、状态（正常 / 加载 / 空 / 错误）、语言（中 / EN）与各页专属切换。**这是评审工具，不属于产品界面，落地时不要实现。**

## 14. 状态规范（所有页面通用）

| 状态 | 规则 |
|---|---|
| 加载 | 骨架块（灰色 18% 不透明度、1.4s 呼吸，减少动态时静止），保持与真实内容相同的高度与栏宽，避免布局跳动 |
| 空 | 72px 斜体破折号 + 衬线标题 + 一行说明 + 一个动作按钮；说明要指出下一步（例如“成为第一个写下精读的人”） |
| 错误 | `role="alert"`，72px `500` + 标题 + 以“错误：”开头的说明 + 橙色“重试”；说明里保留“你的内容 / 阅读位置已保留” |
| 操作反馈 | Toast（橙底黑字，3.2 秒，`role="status"`）；状态变化同时在按钮或标签上用文字呈现 |

## 15. 国际化（文学平台补充）

- 界面文字由 `data-en` 对照；作品正文保持原语言，不做机器翻译。
- 类型名、导航、按钮、分页、状态说明已提供英文；英文下的标题行宽用 `text-wrap: balance`，作品行标题最多 2 行。
- 作品若有其他语言版本，阅读页顶部显示语言入口；没有则不显示，不做空占位。

## 16. 响应式（容器查询）

设计稿使用容器查询（`@container`），断点 `1023px`、`767px`。移动端：竖脊隐藏，导航条收成 `搜索 · 铃铛 · 选单`；阅读页的左侧操作列移到正文下方成一行，右侧批注改为行内标记；发现页的筛选区变成可折叠面板；作者主页左栏变为顶部区块。
