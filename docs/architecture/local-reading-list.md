# 本机阅读清单、续读与文章内查找

本轮基线：`ba5c73b1915e74fe7a444f85f31755b1adc834af`。这是供审阅的增量功能，不改变 API 授权、收藏/关注、划线笔记、作品或媒体的持久化规则。

## 产品边界

仓库是文学阅读与发表产品。本轮在已有阅读器上提供三组相连的能力：

1. **本机阅读清单**：主动保存作品的具体语言版本，管理待读/在读/读完；本地检索、筛选、排序、分页、批量操作与带预览的 JSON 备份/恢复。
2. **明确同意后的阅读位置**：加入清单不等于跟踪。每个版本分别开启，默认关闭；只有主动阅读移动才记住位置。再次打开不会自动滚动，读者点击续读后才定位。
3. **文章内查找**：在当前已加载的正文内作字面匹配，不向服务端发查询；中英文、大小写与宽度折叠、上一处/下一处和键盘操作；Custom Highlight API 不改写服务端正文 DOM。

阅读记录只在这个浏览器里，匿名与登录完全相同；共用浏览器也会共用记录。它不是账户收藏，不提供跨设备同步、离线正文下载、网络检索、遥测或后台上传。页面、筛选、备份都不会调用新的 API。备份会包含读者的阅读位置，界面明确提醒其隐私性质；导出不包含划线笔记、账户信息或位置记忆许可。现有作品阅读计数等已交付能力保持不变；这里的“不上传”仅指本轮清单、位置和查找词，并非声称文章页没有既有网络请求。

## 验收行为

- Given 新浏览器，When 仅访问文章，Then 不创建任何阅读清单或进度键；主动加入后仅保存公开作品标签，tracking 仍关闭。
- Given 同一 slug 的中英文版本，When 分别保存，Then 是两条独立记录，链接只由验证过的 locale/slug 重建，不接受导入 URL。
- Given 多标签页，When 修改不同作品，Then 不整表覆盖；同一作品的陈旧 revision 拒绝覆盖。生产写入使用同源 Web Locks 串行整个读取/比较/写入区间，不把 localStorage 的 get/set 冒充原子 CAS。不能获得安全写入能力时保留读取/导出并显示原因。
- Given 导入、清空或批量操作预览，When 记录或 revision 已变化，Then 拒绝陈旧意图；多 key 写入失败时如实报告已确认条数，不声称浏览器支持事务。
- Given 存储拒绝、容量不足、损坏记录或超过 200 个语言版本，Then 不显示未确认的保存成功，不偷偷丢弃旧条目；显式清空只移除阅读清单 namespace，不影响划线、主题或账户。
- Given 开启位置记忆，When 用户阅读后离开再回来，Then 保留旧位置但不自动定位；点击续读时验证段落文字 witness 与指纹。修改、缺失或重复歧义不作含糊跳转，已有 fragment 优先。
- Given 续读/查找等待下一帧，When 有新指针、键盘、滚动、路由、原生 dialog 或身份/条目变化，Then 旧意图不能抢焦点；卸载释放任务、临时 tabindex、高亮与下载 URL。
- Given 查找，Then 只处理当前正文、不包含评论/划线 UI；组合字符和兼容展开保留原文 offsets；字面匹配而非动态正则，200,000 码元/200 匹配/100 查询码元上限可见。无 Highlight 能力时仍可定位和阅读文字摘录；缺少 `Intl.Segmenter` 时明确提示使用浏览器自带查找，正文和其他阅读工具仍可用，不让模块初始化错误使整页失效。
- Given SSR/HTML/data/HEAD，Then 阅读清单只输出不含本机记录的 no-store/noindex 空壳，不读 cookie，不尝试认证，不将阅读状态放进 URL、sitemap 或公共缓存。

## 风险与验证

位置写入采用约一秒的节流；隐藏文档或 SPA 离开时尝试提交已采样的位置，整页离开会撤销尚未完成的锁任务。最后一秒的未确认移动不保证在关闭/崩溃后保存，界面明确提醒；不以无锁同步写回避生命周期限制。

风险等级：**中**。核心是浏览器隐私、损坏/并发写入与键盘焦点；没有数据库迁移或新的服务端权限面。高风险分支以纯模型/存储和锁协调测试为主，真实双页面浏览器覆盖跨标签页、文件预览、拒绝存储、撤回许可、续读/查找生命周期和实际键盘行为。HTTP 测试覆盖无认证 shell、缓存、SEO 与无 API 读取；最终执行构建、完整类型/静态检查、根测试、Web、真实 PG 与完整浏览器回归。

本轮还补充 Node 测试的 GitHub failure annotation 输出，以便日志下载受限时仍可从 check API 取得失败测试名/断言；不改变测试清单、退出码或 required-checks，不计入有效产品功能行。

所有有效功能行以固定基线后的生产 TS/TSX 增量独立审计；测试、文档、审计/自动化脚本、配置、字典、静态展示、字体生成物、搬移/提取/重复均排除。已有未提交草稿先保留快照、审阅及补足集成，不把编译通过或未接入的草稿当作完成。
