# 全量作品目录与回收站管理

Status: active

本轮固定增量基线 `81bd4b7bcb82b48ad28e15542072f8f6119a29fc`。现有写作台每种语言只显示最近 100 个版本；不提高这个全正文接口的限制，而增加独立的轻量、私有、可分页目录。开放 #284/#286 涉及写作台信息层级，但本功能不以此关闭整个 backlog；运维部署及格式门禁不在本轮范围。

## 行为与验收

1. `/write/library` 展示账户自己的在用作品或回收站，按标题/摘要字面检索；组合语言、发布状态、作品类型、版本活动日期范围筛选，支持最近更新/最早创建两种稳定排序。默认一页 20 个版本，最多 50；支持上一页/下一页与重新开始，不下载正文、不截断为最近 100 个。
   创建/更新时刻使用该语言翻译行的时间；回收站的最近活动使用整部作品的删除时间，不能把某一语言的新编辑算作所有语言都已更新。
2. 目录的计数与分面明确以“语言版本”为单位，同时给出独立作品数；计数应用检索、范围、时间边界，但语言/状态/类型分面在这些三个筛选之前计算，避免选择后把其他选择假装成零。每次响应是数据库语句级读时视图，不承诺跨请求或三个统计/分面/列表查询的快照。并发更新可能移动行，界面提供重新开始。
3. 游标包含排序时间、作品 id、语言以及账户/规范筛选的摘要，不是权限凭据；解码有长度、版本、字段、日期和绑定校验。每条数据库查询仍以服务器验证的 actor 为所有权条件，客户端 id/游标均不能建立身份。相同时间的不同作品、同作品不同语言均有确定序。
4. 可选择已查看的目录条目（上限 100）下载 CSV 索引。明确仅为选中元数据，不是完整文稿备份、不含正文或图片。单元格统一引用/转义，保护电子表格公式及控制字符；不附加账户、revision 或访问凭据。筛选改变清除选择，翻页保留选择；重新核对页面时更新相同键的快照。
5. 在用目录条目可明确打开指定语言版本：通过私有详情接口按 id+locale 获取正文，先验证当前账户；支持不在原最近 100 个列表里的作品。深链接不是保存/创建指令，不绕过既有 dirty/pending 导航保护，不允许延迟读取覆盖后续新建/切换。
6. 同一作品的“查看语言版本”按所有权和在用/回收站范围一次读取最多三个轻量版本，不受当前列表筛选影响。明确列出已存在/缺少的语言、各自标题/摘要和时间，可选择两个版本查看标题/摘要的文本差异；复用已有有界字素差异工具，既不下载正文，也不声称两个语言应当相同或旧时间意味着翻译过期。
7. 下载前可对明确选中的至多 20 部独立作品执行有界串行只读核对。逐部读取完整轻量语言清单，显示选择时与核对时的元数据差异，不会自动选择额外语言。全部成功且用户明确应用后，才用匹配账户/原选择指纹的结果更新本次索引快照；缺失/失败/取消均不替换，账户变更清空私有核对结果，429 停止队列并与目录共享等待时间，普通服务/网络失败停止剩余队列，均不自动重试。所选清单可跨页逐条移除，永不删除作品。
8. CSV 导出可明确选取元数据列（标题/语言必选），支持按选择顺序、标题自然顺序或版本更新排序。预览只显示前八个条目并明确文件仍为全部所选；报告来自实际待下载字节，披露公式前缀和控制字符处理，不可关闭保护；真正下载前向会话接口重新核验实际当前账户，再次匹配请求世代、选择引用及元数据指纹；核验中锁定导出设置，失败/换账户/改选/离开页面均不生成旧文件，回收 Blob URL。默认列与既有 CSV 索引格式兼容，用户可选不含摘要简表。
9. focus/online/可见性恢复时只合并触发账户核验，同账户不丢选择，账户变化同步清除私有结果。pagehide 在浏览器缓存页面前同步清除目录、选择、内存搜索和下载 URL；BFCache pageshow 只重新确认账户/读取，不重放还原。
10. 回收站还原前显示标题/语言和“还原影响同一作品全部版本、恢复为草稿”的确认；沿用现有还原 API，采用同一 bearer 账户前置核验。失败保留原列表、没有批量删除或新增清除操作；成功重新读取，不在前端假造持久结果。

## 范围、安全与风险

风险 **中**：私有列表与已删除元数据泄漏、账户/筛选变更后的晚到响应、动态列表的游标语义、恢复确认。纯读目录、详情及分面必须 no-store/noindex；私有搜索词仅在页面内存，不放进可分享 URL、遥测、自动浏览器存储或日志。详情链接只包含随机作品 id、语言和限制性 expected-author（不是凭据）；跨账户必须拒绝，不静默打开另一账户内容。

不新增依赖或数据库迁移，不改旧列表默认/语言契约、写作台的保存/revision/精确重试、媒体所有权、签名导入、生产限流或既有阅读/标签功能。保留 SQLite/PostgreSQL 两种适配器；以一个有参数的 SQL 构建器共享查询语义，不能用无限制读全部再内存分页。

目录内存控制器负责请求世代、AbortController、账户绑定、恢复意图与 Retry-After；UI 不吞错误或伪装空列表，旧数据在失败时明确不可执行。CSV 下载 URL 必须回收。恢复只向当前授权 API 写入；目录筛选与选择不改变作品。

## 验证策略

高风险边界测试先写失败：严格参数/游标绑定、两库同一分页/搜索/统计/隔离契约、超过 100 个版本、同时间 tie、SQL 通配符字面匹配、未知 id 的 own-only 详情、异步世代与账户切换、恢复确认和限流。模型/控制器与 BFF 用低层测试；浏览器覆盖实际管理页、深链编辑保存、取消 dirty 导航、CSV、回收站还原、移动/axe 和失败恢复。最终完整根测试、真实 PG 集成、完整 Web、四隔离分片浏览器、typecheck/lint/build/路由检查和精确 HEAD 的 required CI。

独立生产行审计固定上述基线，排除测试、文档、配置、生成物、CSS、type/import、搬移和重复；旧写作工具/阅读工具不重计。只开中文 PR，不自动合并、部署或关闭 issue。
