# ADR 0049: 术语审阅保留全部字面主张，不把偏好词变成替换权限

- Status: Accepted as a read-only addition under the user's delegated development task; no persistence, network input or manuscript-write authorization.
- Date: 2026-11-12
- Implementation: Done — 当前工作分支已实现本机分析、画像、只读审阅和手动报告；实际验证范围和剩余限制见[审阅记录](../../audit/writing-terms-review.md)，不由本状态推断 CI、合并或部署。

## 背景与边界

本轮检索共享模块索引、需求基线、`writing-document`、backup/collection/index/search/browser、
单稿替换、段落重叠审阅、三方合并及调用者和测试。现有集合搜索一次查一个字面串；替换只对当前草稿
计算有限、不重叠的位置；段落重叠审阅发现完整段落候选。它们均不回答多词表的拼写组合、跨稿分布与
同一原文上的竞争主张。本轮不将它们扩展成自动替换，也不扩大本机恢复或密码文件的既有授权。

新增 `/write/terms` 匿名空外壳，`no-store` / `noindex`，查询参数不选择文件或规则。
核心和状态机在 `packages/web-ui`，Web 仅作框架适配；没有 API、数据库、依赖升级或持久存储改动。
进入/退出使用既有整页导航边界；CSP 的 Worker 权限不变。#317、#331 与 ADR 0026/0041–0043 仍是独立门禁。

## 决策

1. 用户明确选择一份已有单篇备份或集合，以及手动输入/明确导入的严格 v1 JSON 词表。
   复用 fatal UTF-8、危险/重复 JSON 字段拒绝、backup/collection 校验和摘要；不自动读目录、账户或 URL。
   单篇原件无集合摘要；显示该区别，不冒称已校验原件签名。
2. 词表拥有偏好词、最多七个变体与字符边界条件。仅默认字面区分大小写和可选 ASCII A–Z 折叠；
   不做繁简、全半角、Unicode 兼容规范化或语义推断。word 边界检查原文相邻 Unicode 字母/数字/标记/下划线，
   不是分词。所有 UTF-16 和代码点坐标始终属于原文，不属于规范化副本。
3. 使用 Aho–Corasick trie/failure/terminal-suffix 链，避免复制继承输出列表。跨组同形、折叠同形、
   后缀、包含和重叠全部保留；不选“最长赢家”，也不把替代拼写判成错误。同组完全相同词条拒绝。
4. 来源重新打开已拥有的序列化快照，不信任调用者可变树或短摘要作相等证据。
   只扫描声明范围内段落、标题单元、引用、列表项；不跨单元或受保护结构断点/令牌，代码块、
   标题字段、摘要、图片说明、URL 属性不在扫描范围。内联格式不改变原文字串。
5. 来源或词表超限整轮拒绝。扫描转移、输出、命中有独立预算；同一原始结束位置的所有有效主张
   全部提交或全部不提交。计算停止明确提供单元编号、原文 UTF-16/代码点前沿和完整前缀计数。
   前沿后所有单元均未覆盖，空计数只是下界。输出/排除计数记录尝试工作，可能包括停止位置的尝试。
6. 词表自查目录独立有界，列全部可容纳的同形/包含关系及包含起点；明确 complete 状态。
   以并查集构建歧义分量，并用独立图遍历验证分量与已列关系相符。目录不完整不删扫描词条。
   关系/分量只表达字面条件，不说明语境等价，分量内任意两词也不一定直接有关。
7. 全局/词组/文稿的主张、精确跨度、重叠团和人工状态分开计数，零单元格不省略。
   按文稿、词组、词条、类别、重叠、审阅状态筛选和排序均不影响全局标记或报告。
   原文只作有界惰性文字展示，高亮用扫描线计数而非平方展开竞争主张；可定位与分页，不拆代理对。
8. 拼写画像仅在同组内按当前比较文字建立拼写类，折叠同形的多个主张仍存在，但类内按原文跨度去重。
   统计各篇拼写集合、相同组合/相同覆盖状态分组、类对共现分区，区分同篇多拼写和跨篇组合差异。
   独立显示 complete/partial/unscanned/outside-scope，不把未覆盖或无合格单元称为完整缺席。
   只比较用户所选两篇的已观察集合；相同集合不代表相同次数、正文、语义或编辑正确性。
9. 当前分析对象 witness、闭集位置 ID 和独立清单检查保护定位、整批标记和报告；不可变嵌套输入、
   原文坐标、扫描顺序、结构边界、计数守恒、词表关系和覆盖均复核，不接纳部分无效标记。
   标记只有“有意使用 / 后续检查 / 尚未核对”，不是可导入的修改计划。
10. 报告只能手动准备、预览、确认，再点击下载；白名单输出全局计数、条件、前沿、关系、画像与本机坐标。
    不输出正文、词表明文、标题、摘要、原文件名、链接、节点 JSON 或上下文。报告超限整份拒绝。
    下载复用 lease，在创建 URL 前后都检查当前权限，释放对象 URL，不把交给浏览器称为落盘成功。
11. 来源和词表各自有读取 fence；任一输入、条件、无效词表中间稿、重跑、取消/清除撤销旧分析、标记与报告。
    即使旧读取/计算忽略 AbortSignal，迟到的结果/进度也无权回填。同步清理可阻止后续工作启动。
    pagehide/persisted pageshow 同步清 DOM，离页/卸载清引用和 URL，实际返回不自动重读。

## 风险与非目标

- 不证明语义一致、作者、归属、引用、媒体权限或服务器身份；偏好不是质量门禁。
- 不写原文件、编辑区、缓存、服务器；不自动替换、恢复、保存、上传、同步、发布或重放。
- 正文和词表在使用时为内存明文；清引用不保证安全擦除，不能防御同源恶意脚本、扩展、系统或旁观者。
- 无明文报告仍暴露摘要、分布、路径和偏移；摘要可被猜测，坐标可推断词条长度。仍是私密元数据。
- 不扩展密码文件载荷白名单，不把报告变成能加密导入或应用的指令。

## 验收与验证

- 独立逐位置 Unicode 朴素 oracle 对照所有同形/重叠主张；确定性生成语料和每类缩小预算核对精确前沿。
- 原文路径/结构断点、严格词表与全量超限拒绝、不可变清单、图分量和计数守恒由模型测试保护。
- 拼写画像用原始 match/span 集合 oracle 逐格/逐文稿对核对；同形主张不冒充多种拼写。
- 迟到的读取、摘要、进度、计算，输入/条件变化、取消、同步隐私清理和创建对象 URL 后撤权均为 test-first。
- 真实生产 Web 的 HTTP 验收保护私有空壳/干净 URL/CSP，少量浏览器旅程保护原生读取、离线、下载、
  原文惰性、手机、键盘、axe、隐私与实际返回。合成过渡事件不冒称 BFCache 实际收纳证明。
- 数值预算、故障恢复和使用流程见[操作说明](../../operations/writing-terms.md)；实际结果见[审阅记录](../../audit/writing-terms-review.md)。
