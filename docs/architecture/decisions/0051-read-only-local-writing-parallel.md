# ADR 0051: 双语与平行文稿对照审阅使用确定性骨架树对齐，不推断翻译质量或自动回写

- Status: Accepted as a read-only addition under the user's delegated development task; no persistence, network input or manuscript-write authorization.
- Date: 2026-11-12
- Implementation: Done — 当前工作分支已实现多语言/平行文稿结构提取、确定性动态规划骨架树对齐、结构不对称与空缺检出、比率离散度统计、得分拆解解释、只读人工审阅与无正文脱敏报告；实际验证范围见[审阅记录](../../audit/writing-parallel-review.md)，不由本状态推断 CI、合并或部署。

## 背景与边界

无浪潮（No Wave）平台此前已具备单篇备份导入、多篇集合组织、段落重叠审阅（ADR 0041）、术语审阅（ADR 0049）以及标点与停顿节奏审阅（ADR 0050）。
然而，对于多语言出版（如中文原稿与英文译稿、简体与繁体修订版）或多个平行修订本，作者与编辑缺乏纯本地的结构对照工具。
现有云端机器翻译或在线对齐工具要求上传完整文稿正文，侵犯未公开发表手稿的私密性；且多数仅做表面字符串匹配，无法识别章节标题漂移、段落空缺、引用外链脱节与插图缺失。

本轮新增 `/write/parallel` 离线只读外壳，`no-store` / `noindex`，URL 查询参数不选择文件或分析条件。
核心算法全部位于 `packages/web-ui/src/lib/`，UI 采用响应式只读工作台组件；不引入任何新的云端持久存储、数据库表、网络 API 或第三方分析服务。
进出遵循独立整页导航隔离边界；CSP、Worker 与沙箱安全边界保持严格独立。

## 决策

1. **显式本机来源与双重栅栏**：
   用户明确选择一份本地集合 JSON 文件（最多 20 篇 / 16 MiB）或文稿备份 JSON（最多 2 MiB）。
   复用 fatal UTF-8 校验与 SHA-256 完整性检查；不自动读取文件系统目录、云端账户或 URL 参数。
   控制器维护双重读取栅栏（read fence），重选文件、切换分析范围或取消操作立即废弃旧回调与报告授权，彻底消除并发竞态。
2. **多语言正文骨架树抽取**：
   在声明范围（`all`、`paragraphs`、`headings`、`structural`）内，单次顺序遍历文稿正文提取骨架单元（`ParallelUnit`）。
   提取结构类型（heading、paragraph、quote、list、image）、代码点长度、章节层级、锚点数字与外部链接哈希；代码块、图片说明与属性不参与对齐。
3. **确定性动态规划（DP）双语对齐引擎**：
   针对每对文稿，采用带权 Needleman-Wunsch 算法求解全局最优结构对齐矩阵：
   - 块类型一致赋予基础契合分；
   - 章节标题层级严格匹配赋高权重，层级漂移（如 H2 对齐 H3）记录异常罚分；
   - 共享数字序列、外链规范 URL 与双向 bigram Dice 相似度提供确定性锚点加分；
   - 长度比例（Character Ratio）与设定阈值比对，避免悬殊对齐。
   - 矩阵满足数学守恒律：已对齐块数 + 左侧缺口数 ≡ 左侧总块数，已对齐块数 + 右侧缺口数 ≡ 右侧总块数；并强制校验单调性，禁止对齐路径回退。
4. **结构不对称与空缺分类审阅**：
   对齐完成后自动检出 5 类结构异常：
   - `missing-block`：单边段落或章节缺失（left-gap / right-gap）；
   - `heading-level-drift`：章节标题层级错位；
   - `link-parity-mismatch`：引用外链集合不对称；
   - `image-parity-mismatch`：插图数量或地址不匹配；
   - `extreme-ratio`：字数长度比例显著偏离全局中位数。
5. **稳健比率统计与离群检测**：
   计算对齐行长度比的中位数、平均值、方差、标准差与中位数绝对偏差（MAD）；
   采用 Tukey 栅栏（IQR fences）分类轻度与极端长短比例离群点，呈现章节间比例漂移。
6. **得分拆解解释与只读人工审阅**：
   对任意对齐行提供瞬时、确定性的权重明细展开（类型契合、层级分、长短比得分、锚点加分），不调用远程 AI，不猜测原文。
   用户可在内存中对各行标注“有意保留 / 需后续校对”，标记仅保存在当前会话内存中，不作为修改计划。
   原文预览采用有界惰性分页（上限 2048 UTF-16 单元），不拆分代理对。
7. **无正文脱敏对照报告与租约控制**：
   仅支持用户在界面核验统计、勾选授权风险确认后，通过 `CollectionDownloadLease` 单次向浏览器交付下载。
   脱敏报告（JSON）仅包含：分析时间戳、集合与文稿校验和、结构相似度百分比、对齐块分布统计、异常汇总与脱敏审阅标记。
   **严格白名单输出：严禁导出任何正文文字、标题文本、摘要文字或节点 JSON 结构。**
   报告文件上限 2 MiB，超限整轮拒绝，不截断。
8. **离页与历史过渡清理**：
   `pagehide` 与浏览器导航过渡时同步清理内存引用与 DOM；离开页面后浏览器返回不自动重读或缓存未提交内容。

## 风险与非目标

- **不评估翻译文字质量或词义对错**：对齐工具基于骨架结构、章节层级与确定性锚点，不充当自然语言翻译模型或语法校对器。
- **不自动修改、润色或替换正文**：只读审阅定位不对称项，所有编辑决策完全交由作者人工处理。
- **内存明文风险**：分析期间文稿解密在浏览器私有堆中处理；清理引用不保证硬件级安全擦除，避免在不受信任的公共设备上分析机密手稿。
- **脱敏元数据敏感性**：报告虽不含正文，但段落长度、相似度与哈希仍属于文稿统计特征，须妥善保管。

## 验收与验证

- 覆盖同构双语、标题漂移、单侧缺失段落、外链/图片不对称、比例极端偏离与超限预算拒绝的完备单元测试。
- Needleman-Wunsch DP 对齐矩阵实施守恒性（conservation）与单调性（monotonicity）断言。
- 独立行数双审计（Babel AST 扫描与 Espree 运行时 Token 复核）严格扣除样板与薄接线，确认有效生产功能行 > 800 行。
- 端到端 Playwright 浏览器自动化覆盖私密重定向、离线加载、零外部网络请求、审阅交互、解释展开、脱敏报告下载与 Axe 无障碍合规。
