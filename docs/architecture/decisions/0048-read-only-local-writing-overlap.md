# ADR 0048: 文稿重复审阅使用有界本机候选，不推断合并或去重权限

- Status: Accepted as a read-only addition under the user's delegated development task; not an authorization for persistence, network reads or manuscript writes.
- Date: 2026-11-12
- Implementation: Done — 当前工作分支已实现只读分析、文稿对概览、按需解释、审阅及无正文报告；本地模型、兼容浏览器、完整根/Web 与路由验收见[审阅记录](../../audit/writing-overlap-review.md)。官方版本/全仓库远端门禁须看具体提交检查；不等于已合并、发布或部署。

## 背景与任务选择

本轮代码审阅核对了共享模块索引、需求基线、`writing-document`、backup/collection 校验、
collection index/search/controller/browser、两稿比较、三方合并、密码文件及其调用者/测试。
`inspectWriting` 有单篇统计与重复标题；集合检索需要已知字面查询；两稿比较与三方合并
负责有序差异/人工取舍，都不回答“所选稿件哪些完整段落值得核对”。

也核对了 issue #284 的界面清单、#317 的格式/Promise 检查缺口和 #331 的生产资格门禁。
本轮选择独立、可离线、没有服务器写入的段落审阅，而非扩大为质量门禁改造或生产操作。
#317、#331 仍是独立工作，既有三方合并的重复/顺序歧义拒绝规则不变。

## 决策与最小边界

新增 `/write/overlap` 空白匿名本机工具。Web 路由仅提供 no-store/noindex 外壳和干净 URL；
算法、审阅、导出与控制器在 `packages/web-ui`，无 API、数据库、依赖升级或生成协议变更。
由用户明确选择一份现有单篇备份或集合。多篇先用既有集合工具准备，不发现目录或自动读账号。

1. 复用严格 UTF-8 本机读取、重复/危险 JSON 字段检查、backup 节点校验、collection SHA-256、
   `inspectWriting`/`writingNodeAt`、原字形差异、分页切片、下载 lease 与 page-transition 清除。
   分析重新打开已拥有的序列化快照，不把可变 parsed tree 或 `writingDraftKey` 当原文相等证据。
2. 文字模式默认原始字面；另行选择 NFKC、非语言特定小写、连续空白折叠。最短长度在该模式后
   按 Unicode 代码点计数。原始文字和完整节点（只忽略对象键顺序）仍独立保留。
3. 将完整相同文字归为一组，保留所有来源编号/路径；按同篇、跨篇或全部范围计算组合数量，
   不展开可能平方增长的位置对。原始文字种类与富文本节点种类分开报告。
4. 近似只用完整五代码点片段的集合 Jaccard；完整字符串作索引键，不用短哈希碰撞当相等。
   倒排索引按文字组而非位置建立；过常见片段整项移除，不能优待先出现的稿件。
   先按集合大小比安全排除不可能达阈值的对，再按完整集合（含常见片段）评分。
5. 原始/规范化文字、单元、索引、单片段 posting、访问、候选、比较和列表均有固定预算。
   来源/规范化总量超限整轮失败；近似阶段预算不足则交付明确带缺口的已完整结果。
   同文字组优先，剩余列表空间保留已完整评分中较高分者；不冒称全局最高或完整无重复。
6. 审阅通过当前分析对象 witness 和闭集 finding ID；只允许“需要后续检查 / 有意重复 / 清除标记”。
   一批标记须全部有效，失败不部分采纳。筛选/分页不丢隐藏标记，也不缩小报告。
7. 原始文字和节点 JSON 都是有界字面展示，不渲染 HTML/链接/图片。复用既有有界字形差异；
   可分页/定位 UTF-16 偏移，不把预览截断点当真实结尾。近似分数不生成修改指令。
8. 对当前两处文字另行按需解释完整五代码点片段交集/并集、每个片段的全部出现位置、
   重复次数多重集比例、共享覆盖和唯一位置片段的一条最长严格递增链。每侧最多 4096 代码点，
   超长不截断解释；诊断不重新发现候选、不改变分数或标记、不进入报告。
   折叠模式的位置明确属于规范化文字，不伪装为原文/编辑器坐标；顺序链不是富文本对齐、移动判断或编辑计划。
9. 按至多 20 个文件内文稿编号汇总已列候选的最多 210 个无序文稿对（含同篇）。
   用组合计数核对原 finding 配对数，保留近似组在两文稿间的两个方向，不展开位置对。
   概览也显示没有合格/已列位置的文稿，不把未列位置当作无重复；各对的 finding 数不可相加冒充全局项数。
   点击文稿对同时限定列表和左右位置选择器；全局标记、报告和覆盖口径不变。
10. 报告手动准备、预览并另行确认下载；仅全局已列 finding、闭集条件/计数/限制、文件内坐标、
    集合摘要和标记，不含正文、标题、摘要、文件名、URL、节点、诊断片段或片段筛选文字。
    它是 export-only，不能导入应用。
11. 换文件、有效条件变化、数字条件编辑中的无效中间值、取消或重新分析均撤销旧分析/标记/解释/报告。
    读取、摘要、进度、分析和按需解释均 fenced；即使旧实现忽略取消信号也不能回填新状态。
    换位置或关闭核对会取消并清空该位置的解释，旧面板清理不能取消新位置的解释。
    复用 `document-navigation` 为本工具建立双向整页导航边界，避免干净 URL loader 被 Router 数据查询参数干扰；
    不改变其他普通页面的 SPA 规则，也不放宽 Worker/CSP。离页/组件卸载清理；
    pagehide 与 persisted pageshow 同步清 DOM，实际返回不自动读文件。

## 非目标与风险

- 不是查重/抄袭证明、语义或翻译匹配、作者签名、共同来源、所有权、媒体权限、服务器身份或提交回执。
- 不自动删除、配对富文本节点、修改编辑区/原稿/恢复缓存/服务器，不重放请求或自动发布。
- 不跨段拼接；代码、标题/摘要字段、图片说明不在比较范围；完整片段集合忽略频率和顺序，
  所以近似 100% 也可能不是同一文字。常见模板与预算都可能造成误报/漏报。
- 明文、索引、节点和临时标记在使用中驻留内存；同源脚本、扩展、系统、旁观者仍是风险。
  清理引用不保证物理擦除。报告虽无正文，摘要/坐标/计数仍须作为私密元数据保管。
- 不变更密码文件白名单，不给新报告暗中增加加密/解密导入能力；不持久化审阅计划。
- 不部署、配置账号、改基础设施或关闭 ADR 0026/0041–0043 与 #331 的独立门禁。

## 验收与验证层

- Given 合法手选备份，When 分析，Then 原始文字/路径不变，相同文字不冒充相同节点，
  跨篇/同篇数量与独立组合公式一致；独立 Unicode 全量小语料 oracle 核对每个近似分数。
- Given 常见片段、超长组或任何计算预算，When 分析结束，Then 缺口逐项可见，
  未完成的组对没有假分数；规范化膨胀仍受总预算限制。
- Given 新来源/条件/取消/离页，When 旧异步读取或摘要完成，Then 不能复活私密 DOM、标记或下载。
- Given 隐藏项目、文稿对筛选或未核对候选，When 下载报告，Then 全局计数与未核对状态仍保留，
  报告不含私密正文、片段或筛选词。文稿对聚合由独立的全位置小语料 oracle 核对；400 个重复位置
  的 79800 个位置对仍只产生 3 个文稿对单元，不创建位置对数组。
- Given 片段集合相似 100% 但重复次数不同，When 按需解释，Then 次数差异、全部位置和规范化坐标可核对，
  不把这个诊断升格为原文相同；顺序链长度还由独立的二次递推 oracle 核对。
- 单元测试保护算法、原文不变、事务式选择、并发/取消及报告；真实生产 Web 的 HTTP 测试保护
  私有外壳/重定向/CSP；少量浏览器旅程保护离线、原生 FileReader/Web Crypto、键盘、手机、axe、
  下载与导航。不把合成 page-transition 事件称为真实 BFCache 实验。
- 所有实际通过、跳过、不可用、待运行结果及本轮独立有效代码行审计留在[审阅记录](../../audit/writing-overlap-review.md)。

操作流程和精确上限见[使用说明](../../operations/writing-overlap.md)。
