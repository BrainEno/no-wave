# ADR 0050: 写作停顿与配对节奏审阅使用单次有界扫描，不推断行文风格或自动润色

- Status: Accepted as a read-only addition under the user's delegated development task; no persistence, network input or manuscript-write authorization.
- Date: 2026-11-12
- Implementation: Done — 当前工作分支已实现本机停顿扫描、配对闭合、停顿边界交叉画像、只读审阅和手动无正文报告；实际验证范围和剩余限制见[审阅记录](../../audit/writing-cadence-review.md)，不由本状态推断 CI、合并或部署。

## 背景与边界

本轮检索共享模块索引、需求基线、`writing-document`、backup/collection/index/search/browser、
单篇替换、段落重叠审阅、三方合并、密码文件备份与术语审阅。既有工具聚焦于字符存在、拼写组合、
段落相似度与文本合并；均不提供长短句交替、停顿标点分布、括号/引号成对嵌套跨度、配对与停顿边界交叉
及隐形排版字符的结构画像。本轮不引入自然语言风格判断、阅读难度打分、自动润色或排版格式化，
也不扩大本机或云端的既有写入权限。

新增 `/write/cadence` 匿名只读外壳，`no-store` / `noindex`，查询参数不选择文件或分析规则。
核心状态机与分析算法均在 `packages/web-ui`，Web 仅作框架与无状态路由适配；不引入新的持久存储、
API 接口、数据库表或第三方运行时依赖。进入与离开使用整页导航边界；CSP、Worker 策略与门禁
#317、#331 与 ADR 0026/0041–0043 保持独立。

## 决策

1. 用户明确选择一份已有单篇备份 JSON 或集合 JSON。
   复用严格 fatal UTF-8、危险与重复 JSON 字段拒绝、backup/collection 校验和与摘要；不自动读取
   本地文件系统目录、账户云端数据或通过 URL 参数指定输入。单篇原件无集合摘要，界面明确标注区别。
2. 扫描采用确定性单次流式扫描，严格在声明范围内（`all`、`paragraphs`、`headings`、`quotes`、`lists`）
   提取正文文字单元；代码块、标题属性、摘要字段、图片说明与外部链接属性一律不参与扫描。
   不跨正文单元或受保护换行/结构断点拼接跨度；遇到无法完整安全提取的节点整轮拒绝。
3. 停顿节奏按标点符号明确分类：句末终结符（句号、问号、叹号等）切分片段；逗号、分号、冒号、
   破折号等作为片段内部停顿记录；西文句点根据前后数字与缩写规则精确判定，避免将小数与缩写误认为句末。
   片段按代码点长度划分为过短、正常、过长片段（默认阈值 12 与 120），直观呈现停顿疏密。
4. 成对符号（双引号、单引号、各类括号、书名号等）使用显式栈进行对称与嵌套匹配，最大嵌套深度限制为 128；
   超深嵌套直接记录未闭合异常并截断，防止恶意构造导致调用栈或内存溢出。
   引号支持关闭、仅双引号或全部引号匹配策略；未闭合、孤立闭合或错位交叉成对符号均生成独立审查 finding。
5. 针对配对跨度与停顿边界的交叉关系统计（`cadencePairRhythm`），采用反向区间 join 与差分扫描算法
   （时间复杂度 O(pairs · log fragments + fragments)），严禁物化 pairs × fragments 笛卡尔积。
   严格校验起终点游程一致性（同 run），跨 run 跨度立即拒绝；差分扫描核算各边界穿透深度，
   并强制实施数学守恒检查（所有配对跨边界次数之和必须严格恒等于全部缝隙深度之和），不一致整份拒绝。
6. 隐形字符扫描覆盖零宽空格、零宽连字符、双向文本控制符（LRE/RLE/RLO 等）以及各类异常格式化控制符；
   全部以代码点（如 `U+200B`）精确归类与统计，并提供定位样例，不静默擦除或自动转换。
7. 审阅列表提供配对、片段与异常三类行；支持按文稿、类型与标记状态筛选；
   原文预览采用有界惰性分页，每次最多渲染 2048 个 UTF-16 代码单元，不拆分 UTF-16 代理对。
   人工标记仅包含“有意使用 / 后续检查 / 尚未核对”，只保留在当前会话内存中，不作为修改计划。
8. 报告仅支持手动准备、预览、勾选风险核对后手动触发下载；报告采用严格白名单，仅包含全局计数、
   分布直方图、配对画像与本机偏移/摘要；严禁输出原文正文、标题、摘要文本、文件名或节点 JSON。
   报告生成超出大小限制整份拒绝；下载完成不代表文件已成功落盘。
9. 控制器实现双重读取栅栏（read fence），任何文件更换、策略调整、无效数字草稿、重新分析或取消
   均立即撤销旧分析、旧标记与下载授权，迟到的异步回调无法回填过期数据。
   `pagehide` 与历史导航过渡时同步清理 DOM 与引用，返回页面时不自动重读。

## 风险与非目标

- 不推断作者意图、修辞优劣、语言风格或可读性分数；长短句与配对嵌套仅作客观统计，不是质量裁决。
- 不提供自动断句、自动加标点、自动补全括号或排版美化功能；本工具为只读审阅，不修改原文。
- 分析期间文本在浏览器内存中为明文；清理内存引用不构成安全擦除，无法抵御同源恶意脚本或系统级窥探。
- 无明文报告虽然去除了原文，但其分布特征、片段长度与坐标仍属于私密元数据，可能被统计推断；报告不得公开。
- 不接入任何网络接口，不扩展密码文件格式，不提供自动化脚本执行或批量转换入口。

## 验收与验证

- 针对停顿切分、配对匹配、嵌套深度、差分交叉扫描与隐形字符建立完备的单元测试与守恒性断言。
- 采用反向二分与差分扫描核对配对×停顿边界深度，所有测试用例强制验证端点守恒与 run 连续性。
- 控制器双读取栅栏、取消竞态、无效策略草稿与隐私清理全部经自动化测试保护。
- 独立行数双审计（主审计与独立验证器）严格执行，扣除所有薄封装、配置与通用状态机，生产功能行真实确认。
- 端到端浏览器旅程验证匿名访问、文件选入、策略切换、画像查看、明细定位、无明文报告下载与离页清理。
- 详细操作步骤与参数限额见[操作说明](../../operations/writing-cadence.md)；实际结果见[审阅记录](../../audit/writing-cadence-review.md)。
