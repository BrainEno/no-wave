## 范围与可观察行为

1. **未保存保护**：标题、正文、摘要、语言或类型的实际语义改变会提示未保存；初始 hydration、选择移动、纯序列化默认值和撤销到基线不应制造假脏状态。离开路由、切换作品、新建或退出前确认；现有“上次保存尚未确认”的重试保护优先。失败、格式错误、冲突或只确认了旧快照不能把后来编辑标成已保存。
2. **文稿检查与大纲**：派生字数/词组数、预计阅读时长、块/图片/链接统计、标题层级、重复标题、空正文/替代文本等可执行检查；不对文风评分，不以客户端检查替代服务端校验。每节统计包含下级标题，遇到下一个同级/更高级标题结束，不计代码和图片描述，以前缀和避免重复扫描全文。点击大纲/问题仅定位当前有效节点，不上传正文；不支持的节点显式报告。
3. **正文查找替换**：字面匹配，默认区分大小写；可限制为段落、标题、引用、列表项或全部可替换正文，不改变链接目标或图片/代码内容。先预览、再选择替换，绑定完整编辑器快照，陈旧预览拒绝执行；支持上一处、下一处和逐项精确选择正文。跨行内格式匹配保留匹配之外的内容，替换文字采用首个匹配字的格式；整批操作可一次撤销。查询和替换长度、正文扫描和结果数均有可见上限。
4. **本机文稿备份/恢复**：下载版本化 JSON，支持纯文本与 Markdown 导出；恢复只读取本地文件并展示字段/正文块差异，作者选择字段后才更新编辑区，不自动保存、发布或创建作品。正文可以替换全文，也可保留当前正文、按备份文件顺序追加勾选的块，组合校验失败不会部分恢复元数据。差异区分增删、改动、位置移动、格式/链接变化，片段按字素安全截断。文件不携带账户、作品 ID、slug、发布状态、revision、令牌或重试键；恢复不改变这些服务器事实。Markdown 是有明确损失提示的交换格式，不承诺再导入或替代 JSON 备份。
5. **离线链接与图片清单**：在文稿检查中按需展开，规范化安全地址后分组，保留每处节点路径；可按链接/图片、仅警告筛选并定位。提示空文字、HTTP 和同名异址，不自动请求 URL，不宣称地址可达或媒体归属；危险地址原值隐藏。最多 200 组、1000 处引用，每组只展示前 50 个定位入口，达到预算即停止读取后续子节点并说明结果不完整。

## Given / When / Then

- Given 未保存正文，When 切换作品/新建/退出/内部导航，Then 必须确认；取消仍保留原输入，确认只授权被展示的那个编辑器版本。
- Given 保存正在请求，When 作者继续修改，Then 成功只确认提交时的快照，后来修改仍是脏状态。未知结果重放以服务端返回的实际内容为准。
- Given 查找/恢复预览，When 正文、格式或任一相关字段改变，Then 预览作废，不猜测把旧位置/选择应用到新内容。
- Given 富文本匹配横跨粗体、链接或换行，When 替换，Then 链接 URL、未命中文字与其他块不变，撤销可恢复整个操作。
- Given JSON 包含未知版本/节点、危险 URL/字段、超限内容或损坏结构，Then 在调用 Lexical 导入前拒绝，不渲染 HTML、不请求远端图片、不接纳身份或保存前置条件。
- Given 文件读取尚未完成，When 另选文件、取消、卸载或切换文档，Then 旧读取不能覆盖新预览或文稿；下载 URL 和焦点/定时任务释放。
- Given 保存未确认，Then 本机备份仍可导出当前输入，但恢复/替换不能改写现有请求的重试协议；不自动重发/放弃请求。
- Given 备份包含远程图片，When 只读取/预览或仅恢复元数据，Then 不请求图片；只有正文恢复且作者明确同意后才允许编辑器载入所选远程图片。站内媒体最终仍由服务端验证所有权。
- Given 正文追加模式，When 勾选顺序不同于文件顺序，Then 仍按文件顺序追加、保留未选中的当前内容、一次正文撤销可还原；标题等字段不属于富文本撤销栈。
- Given 初次打开已保存的列表、代码或同地址相邻链接，Then Lexical hydration 的默认值与合并不制造未保存警告；工具导出的运行时 JSON 可以重新预览而不产生假差异。

## 本地文件和性能边界

JSON 只接受 `no-wave-writing-backup` v1，拒绝未知字段、原型污染键、危险 URL、非注册节点及不能保留的元素/行内格式。原始文件最多 2 MiB；编辑快照序列化最多 1000000 字符，正文最多 500000 字符/12000 节点/200 顶层块，每列表最多 100 项，递归深度有硬限制。备份校验在任何 Lexical `importJSON` 之前完成。查找最多预览/应用 200 项，查询最多 200 字符，替换文字最多 1000 字符；不会隐式替换未展示匹配。

文稿检查与引用扫描在预算处停止子节点读取，不只截断最后的结果列表；超出 200 个顶层块时明确标记检查不完整，禁用依赖完整检查的替换和章节统计。文稿工具关闭时不扫描正文；引用清单另行按需计算。文件读取使用取消/卸载世代和完整快照 witness；对象 URL 在延迟回收或卸载时释放。下载文件名采用可移植 ASCII，中文完整标题仍保存在文件内容中。

## 风险、最小边界与验证

风险：**中**，集中在丢稿、富文本损坏、陈旧意图与本地文件隐私。浏览器确认不能保证崩溃/移动端强制退出时保留内容，本机文件也不是加密存储；界面会说明。没有自动 localStorage、IndexedDB 或网络备份，不建立新的私有数据持久化策略。

生产边界为 `packages/web-ui/src/lib/writing-*`、写作工具组件及现有 ArticleEditor/AuthoringWorkspace 的窄接线。保留 API revision/expected actor、未确认创建的精确重试字节、签名 Notion 导入、媒体所有权、限流与已有产品能力。JSON 备份是版本化本机编辑快照，不作为 REST/数据库长期内容合同；恢复后仍经既有 API 的应用文档适配器和授权校验。

先对快照确认竞态、危险文件、陈旧替换/恢复作纯模型 Red→Green，再做真实 Lexical/浏览器输入、IME/撤销、原生确认框、文件下载/读取竞态、路由与保存并发；最后执行完整根/Web/真实 PostgreSQL/浏览器、类型/静态/契约/构建与本 PR 精确 HEAD 的 required CI。有效新增生产功能行对本轮固定基线独立审计，排除测试、文档、配置、字典、静态展示、生成物、搬移与重复。
