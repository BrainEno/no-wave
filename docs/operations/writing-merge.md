# 本机三方文稿合并：使用与失败处理

入口：写作台、作品目录或本机集合工具中的“本机三方合并”，路径 `/write/merge`。
页面本身可以匿名打开；这是文件工具，不是服务器修订冲突的自动解决器。
设计与授权边界见 [ADR 0046](../architecture/decisions/0046-local-three-way-writing-merge.md)。

## 开始之前

- 另外保存好三份原始文件：两份改稿的**共同起点**、当前稿、另一稿。相似标题、文件名或
  时间不证明共同来源；若找不到可靠的共同起点，请用现有两稿比较，不要猜一个基线。
- 只接受现有写作工具导出的单篇 JSON 备份。集合文件先在 `/write/collections` 手动拆分，
  不接受 Word、HTML、Markdown 或把集合的第一篇偷偷选来合并。
- 每份最多 2 MiB，须为有效 UTF-8；节点、文字、格式、链接、块数仍受既有备份限制。
  原文件和下载文件未加密，可能含私密正文和地址，不适合留在共用设备或任意分享。
- 页面载入后可离线操作；需要支持 Web Crypto/SHA-256 的浏览器和安全上下文。
  无法校验时会明确失败，不降级为弱摘要。

## 一次完整操作

1. 在三个角色槽位分别选择原文件，核对标题、摘要、语言、类型、块数和备份时间。
   界面只显示文字，不会请求图片或跟随链接。选择文件不等于分析或应用。
2. 勾选“我已核对角色，确认共同基线是两份改稿的共同起点”，再点击分析。
   分析前会重新严格校验三份文件，绑定完整备份摘要和角色。
3. 在“逐项审阅”中查看建议和冲突。每项只能取共同基线、当前稿或另一稿之一；
   可以覆盖无冲突建议，或重置此项回到建议/未解决状态。
   选中零块的候选表示明确删除该区间或不插入，并不是读取失败。
4. 用筛选、分页与前后未解决冲突定位核对全部项。隐藏的选择仍保留、仍参与最终校验。
   重复段落或顺序歧义会使整个正文成为一个冲突，不自动猜对应段落或同时追加两稿。
5. 纯文本相同也可能格式或链接目标不同。展开“相对基线的结构差异”和“精确 JSON”
   核对；结构路径只是只读位置诊断，不是段落身份或编辑指令。诊断达到预算会说明
   不完整；数组长度改变时只报告长度，不猜后续位置。必要时显式展开完整文字。
6. 所有冲突取舍后，点击“校验并准备合并结果”。工具会独立核对逐来源完整性、
   合成后各项选择和完整备份合同；只要组合超限就整份拒绝，不截断导出。
7. 核对输出标题、摘要、语言/类型、正文、来源块数和格式提示。展开“核对未采用改动与
   来源完整对照”，逐来源核对完整正文/根属性/字段，并检查未采用候选、覆盖建议、回基线
   与零块取舍；可分页/筛选并按需展开候选精确 JSON，不会改变取舍。候选未采用不是
   逐字丢失判定；请核对完整文意。之后勾选未加密风险说明，
   再下载**新的合并文稿 JSON**。这不会修改原文件、当前编辑区或服务器。
8. 如需继续写作，在既有写作工具中重新选择这个新文件、预览并选择要恢复的字段。
   原有语言/停用类型、远程图片同意、媒体所有权、revision 和未知保存请求保护继续生效。
   本机结果有效不等于已经保存、可发布、拥有图片权限或原写入已经成功。

## 暂停与决策计划

- “准备人工取舍计划”再下载，可保留尚未完成的选择。计划不包含正文、标题或本机文件名，
  但包含三份来源摘要，仍可能被用来关联文件。请另外保管三份原始备份。
- 继续时重新选择同一角色的三份原始文件、确认基线、分析，再手动预览计划。
  备份时间也在来源摘要内；重新导出同样文字但时间不同的文件不是同一个来源。
- 计划只预览不应用。确认区会列出新增、更改、清空和回到默认的人工选择；另行勾选后
  才**完整替换**全部人工取舍，不是把新旧计划悄悄合并。应用会撤销旧合并结果。
- 计划最多 64 KiB；坏时间、版本、来源/角色、条目、重复键或摘要都会整份拒绝。
  SHA-256 只是完整性校验，不是作者签名；能修改计划的人也能重算摘要，因此须人工复核。

## 取消、失败和隐私

| 情况 | 实际行为与下一步 |
| --- | --- |
| 选错文件、文件太大、UTF-8/JSON/节点/URL 不合法 | 该槽位失败，不部分接纳；其他原文件仍在。重新选择正确文件。 |
| 读取长时间不完成 | 用该槽位“清除文件”取消，之后重新选择；不会因此自动联网或反复读取。 |
| 分析/结果/计划正在运行 | 可明确停止；换来源会使全部旧派生工作失效，迟到结果不能覆盖当前状态。 |
| 改人工选择又改回原选项 | 原准备工作仍然作废，不利用字面相同绕过取舍 revision；重新准备。 |
| 组合后超过 200 块、文字/节点/字节或其他限制 | 明确显示错误，无结果下载；回到取舍核对，不会静默丢弃尾部内容。 |
| 仍有未解决冲突 | 禁止准备输出；可手动保存不完整的决策计划。 |
| 改来源、清除文件或撤回基线确认 | 同步清除分析、人工取舍、计划和结果，重新确认/分析；不修改磁盘原文件。 |
| 计划来源不匹配 | 不应用旧选择；找回原三份文件，或重新逐项取舍。不要手工篡改摘要来伪装来源。 |
| 下载失败 | 显示失败，释放对象 URL；原文件仍在，核对后重新准备/下载，不冒充已写入服务器。 |
| 离开、进入历史缓存或返回 | 清除本页来源与派生 DOM，返回不自动重读。请在离开前手动下载所需文稿和计划。 |

没有 localStorage/IndexedDB/Service Worker 自动存稿，也没有上传、账号同步、请求队列、
自动导入、发布或重放。清除只处理本页内存和对象 URL，不删除已下载文件，也不承诺
浏览器进程内存、开发工具、系统交换区、截图或物理存储安全擦除；同源脚本/XSS、扩展和
共用设备风险仍然存在。

本功能不完成生产主机、跨主机、邮件/通知到人、密钥、备份/回滚或其他运维资格。
#331 和既有发布门禁保持独立；合并 PR 不是部署或破坏性服务器操作的许可。
