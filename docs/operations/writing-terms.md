# 本机术语一致性审阅

Status: active

入口 `/write/terms`，也可从写作台或本机集合工具进入。无需登录，不需要 API；不是自动替换或在线词库。
设计边界见 [ADR 0049](../architecture/decisions/0049-read-only-local-writing-terms.md)。

## 明确的手动流程

1. 选择一份现有单篇备份 JSON（最多 2 MiB）或集合 JSON（最多 20 篇 / 16 MiB）。
   多篇先用集合工具准备。不读目录、账户、查询参数中的地址；单篇原件没有集合摘要，页面会说明区别。
2. 在“术语词表 JSON 草稿”输入完整词表，或明确选择本地词表 JSON；演示按钮会**覆盖当前草稿**。
   结构如下；偏好是用户的审阅标签，不是系统判定的正确拼写。

   ```json
   {
     "format": "no-wave-writing-terms",
     "version": 1,
     "rules": [
       {
         "preferred": "无浪潮",
         "alternatives": ["無浪潮"],
         "boundary": "substring"
       },
       {
         "preferred": "No Wave",
         "alternatives": ["NoWave"],
         "boundary": "word"
       }
     ]
   }
   ```

   不允许未知字段、重复 JSON 字段、同组完全相同的重复词条、首尾空白、控制符、双向控制符或不完整代理对。
   `word` 检查原文相邻 Unicode 字母、数字、组合标记、下划线；不是中文分词。
3. 默认区分大小写的原始字面；可改为**仅 ASCII A–Z** 折叠。没有繁简、全半角、NFKC、词干或同义词转换。
   明确选择正文范围后点击“分析本机术语分布”；更改词表（包括无效中间稿）立即撤销旧分析。
4. 先读覆盖与前沿，再看词表同形/包含关系。所有跨组同形、包含、后缀、重叠主张均独立保留。
   关系分量不代表所有成员两两直接相交；目录不完整不意味着正文用了部分词表。
5. 按词组、文稿、词条和审阅状态查看，定位到原始单元。高亮双下划线为所选主张；同一片段可能有多个主张。
   坐标为从零开始的 `[start, end)`，结束位置不含；UTF-16 与代码点均为原文位置，不等于组合字形。
   长单元用有界分页与原始字符偏移跳转；不会把截断预览称为全文。
6. 拼写画像把同组在当前比较模式下完全同形的词条归为一个类，但不删除任何主张或标记。
   类内按精确原文跨度计位置。查看同篇多拼写、跨篇相同组合与共现分区，再明确选择两篇对照。
   `partial` / `unscanned` / `outside-scope` 不能作完整缺席证据，“相同组合”也不代表相同正文或次数。
7. 只在内存中逐项或对**当前页**标记“有意使用 / 后续检查”；筛选不清隐藏标记，也不缩小全局报告。
8. 点击准备无明文报告，阅读预览并另行勾选核对，然后手动下载。报告超限整份拒绝，不截断。
   实际标记、文件、条件、词表变化或重跑会撤销报告和下载确认。浏览器收到下载不等于文件已成功落盘。
9. 用清除按钮释放本页。离页或历史过渡同步清理，返回不自动重读；应另行保管自己的原件和词表。

## 精确边界与预算

| 内容 | 上限 / 行为 |
| --- | --- |
| 词表 UTF-8 JSON | 128 KiB，1–128 组；每组 1 个偏好 + 0–7 个变体 |
| 词条 | 每条 1–80 代码点；全部最多 512 条 / 16384 代码点 |
| 来源提取 | 所有检查到的正文单元最多 4096 个 / 2000000 UTF-16 代码单元；超限整轮拒绝，不靠缩小范围绕过 |
| 模式自动机 | 最多 16385 状态；超限不编译部分规则 |
| 正文计算 | 4000000 次转移 / 100000 次输出核对 / 5000 个保留命中主张 |
| 同一结束位置 | 所有有效主张全部提交或全部不提交；停止点之前为完整前缀 |
| 词表自查 | 独立最多 4096 关系；额外独立有限扫描预算，触发则明确目录不完整 |
| 拼写画像 | 最多 512 类 × 20 篇单元格，128 组各最多 28 个类对共现分区；不展开原文位置对 |
| 原文/报告预览 | 每页最多 2048 UTF-16 单元；不拆开代理对，但可能分开组合字形 |
| 报告 | 完整 UTF-8 最多 2 MiB；只手动输出，不能导入应用 |

只扫描声明范围的段落、标题单元、引用、列表项。代码块、标题字段、摘要、图片说明、URL 属性不参与；
不跨单元或受保护换行/令牌。来源中无法完整提取的未知正文节点整轮拒绝，不以不完整提取冒充全文。
转移/输出/排除计数是尝试工作，可能包含停止结束位置的尝试；**已覆盖前缀**看 scanned 计数和前沿。

## 故障与隐私

- 无效 UTF-8、重复键、损坏摘要、词表/来源超限：整轮拒绝，修正自己的副本后重新明确选择，不猜测修复原文。
- 没有结果：先检查已覆盖范围、word 字符边界、大小写和正文类型，不推断语义一致或全文未出现。
- 触发计算预算：前沿之后均未覆盖。可手动拆成更小集合/词表分别审阅；不同轮次编号和结果不能直接拼成完整证明。
- 取消/重选后旧工作完成：结果与进度会被 fence 拒绝，不能恢复旧标题、词表、标记、定位或下载。
- 下载失败：重新核对当前预览并手动重试。不会自动重试、保存、上传或写入恢复缓存。
- 报告无正文/词表明文、标题、摘要、原文件名、链接或节点，但保留摘要、分布、路径、偏移和词条长度线索。
  摘要不是加密或签名，可能遭字典猜测；报告仍是私密元数据。
- 使用中正文/词表为内存明文。清除引用不是安全擦除，不防同源恶意脚本、扩展、系统或旁观者。
  本轮没有服务器写入、账号配置、部署、生产运维或外部文档访问。

开发核验与真实通过/失败/不可用记录见[本轮审阅](../audit/writing-terms-review.md)。
