# 本机写作停顿与配对节奏审阅

入口 `/write/cadence`，也可从写作工作区或本机集合工具进入。无需登录，不需要 API 或网络连接；不是自动润色或行文排版工具。
设计边界见 [ADR 0050](../architecture/decisions/0050-read-only-local-writing-cadence.md)。

## 明确的手动流程

1. 选择一份现有单篇备份 JSON（最多 2 MiB）或集合 JSON（最多 20 篇 / 16 MiB）。
   多篇先用集合工具准备。不读系统目录、账户云端或查询参数中的地址；单篇原件没有集合摘要，页面会说明区别。
2. 配置分析策略与阈值：
   - **扫描范围**：全部正文（默认）、仅段落、仅标题、仅引用或仅列表项。
   - **引号配对**：关闭（默认）、仅双引号或全部引号（含单引号）。
   - **句点判定**：是否将西文句点纳入停顿终结符（默认关闭，严格避开数字小数与缩写干扰）。
   - **片段长度阈值**：过短片段上限（默认 12 代码点）与过长片段下限（默认 120 代码点）。
3. 点击“分析本机写作停顿与节奏”；修改策略输入（包括未完成的数字中间状态）或切换文件立即撤销旧分析与标记。
4. 查看“文稿停顿与配对画像”：
   - **停顿片段分布**：各篇正常、过短与过长片段数量及长度范围，直观展现句式节奏疏密。
   - **标点符号频率**：各类句末终结符与内部停顿标点出现频次。
   - **配对嵌套深度**：括号与引号的最大嵌套层级与分布直方图。
   - **配对与停顿边界交叉**：单片段内配对与跨停顿配对数量、穿透边界数、最大深度与样本定位入口。
5. 详细审阅与定位：
   - 按文稿、条目种类（配对、停顿片段、异常 finding）和审阅标记筛选。
   - 点击列表项展开详情，查看配对的起止字符、闭合状态与停顿边界穿透详情。
   - 点击“定位起点片段”或“定位终点片段”，在原文有界预览中高亮对应范围。
   - 原文每次最多展示 2048 个 UTF-16 代码单元，不拆分代理对；提供向前、向后与绝对偏移跳转。
6. 隐形字符审查：
   - 独立统计零宽空格、零宽连字符与双向文本控制符（如 `U+200B`）。
   - 查看出现频次与样例定位，避免不可见字符破坏排版或复制粘贴混淆。
7. 手动标记与报告：
   - 在内存中对条目或当前页标记“有意使用 / 后续检查”。筛选不丢失隐藏标记，也不改变全局统计。
   - 点击“准备无明文报告”，在预览区核对脱敏内容，勾选元数据风险确认后手动下载。
   - 报告超限（> 2 MiB）整份拒绝，不截断；下载交给浏览器不等于文件已成功落盘。
8. 使用清除按钮或离开页面释放所有数据。离页或历史导航同步清理 DOM 与引用，返回时不自动重读。

## 精确边界与预算

| 内容          | 上限 / 行为                                                                                                |
| ------------- | ---------------------------------------------------------------------------------------------------------- |
| 来源文字单元  | 最多 4096 个正文块；代码块、图片说明与链接属性不参与                                                       |
| 来源文本长度  | 最多 2,000,000 UTF-16 代码单元；超限整轮拒绝                                                               |
| 扫描步数      | 8,000,000 步；保障流式扫描在有界时间内完成                                                                 |
| 配对总数      | 最多 50,000 组配对                                                                                         |
| 停顿片段总数  | 最多 20,000 个片段                                                                                         |
| 异常 Finding  | 最多 5,000 项异常标记（未闭合配对、深度溢出、隐形字符等）                                                  |
| 配对嵌套深度  | 最大 128 层；超深截断并生成深度异常 finding                                                                |
| 配对×停顿交叉 | O(pairs · log fragments + fragments) 差分扫描；跨 run 立即拒绝，强制实施 incidences ≡ seam depths 守恒校验 |
| 原文预览      | 每页最多 2048 UTF-16 代码单元；不拆分代理对                                                                |
| 报告大小      | 完整 UTF-8 最多 2 MiB；只手动输出，无导入或回写接口                                                        |

遇到任何结构断点或跨单元边界，绝不跨结构拼接跨度；未覆盖区域保留明确标记，不假称零缺席。

## 故障与隐私

- **文件拒绝**：无效 UTF-8、重复 JSON 键或损坏摘要整轮拒绝，请检查本地原件完整性。
- **无结果或超限**：检查所选范围与阈值；若达到步数或条目预算，未覆盖部分前沿保持可见，可拆分集合后分批审阅。
- **并发与竞态**：重选文件、调整策略或取消操作均由双读取栅栏拦截，迟到的异步分析无法覆盖当前视图。
- **隐私边界**：报告严格去除所有正文文本、标题、摘要文字、原文件名与节点结构；但导出的偏移、片段长度与统计特征仍属私密元数据。
- **内存安全**：页面运行期间正文驻留浏览器内存；清除引用不等于密码学安全擦除，请在受信任设备使用。

开发核验与真实通过/失败/不可用记录见[本轮审阅](../audit/writing-cadence-review.md)。
