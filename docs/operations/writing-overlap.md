# 本机文稿重复段落审阅

入口：`/write/overlap`；写作台及本机集合工具也有链接。设计边界见
[ADR 0048](../architecture/decisions/0048-read-only-local-writing-overlap.md)。无需登录。
应用页面/字体/脚本加载完成后，可断网处理明确选择的本机文件；不从 URL 或服务器自动找稿。

## 使用步骤

1. 在可信设备打开页面，明确选择**一份**现有单篇文稿备份 JSON 或文稿集合 JSON。
   多篇先到 `/write/collections` 手动准备所需集合，再在此选入。一次不会默取多个文件中的第一份。
2. 等待完整读取、严格 UTF-8/JSON/节点/链接校验及集合摘要核对。单篇原文件没有集合摘要，
   工具只为当前内存快照计算摘要；这不是原文件真实性或作者签名。
3. 核对文件内 `d1…d20` 对应的标题。编号只属于这份文件，不是数据库 ID，不获得媒体或写入权限。
4. 选择文字模式、范围、最短段落长度（8–500 代码点，默认 24）与近似阈值（50–95%，默认 65%）。
   默认原始字面、跨不同文稿；只有一篇时可选择各篇内部。点击“分析本机段落重复”。
5. 先读覆盖/缺口，再审阅列表。**同文字组**保留每处独立路径；富文本节点种类不同可能意味着格式、
   链接、节点类型不同。**近似候选**只是五代码点片段集合相似，不是去重建议。
6. “只读核对”后明确选左右位置。选择器只列出当前范围内能配对的位置；同一位置不能与自己配对。
   各级位置从 1 显示（如列表项为 `3 / 2`）；报告保留从 0 开始的真实路径数组。
   每页最多 12 处可选位置，切换位置页不会偷偷换掉已选位置；可返回已选位置所在页。
7. 原文/节点 JSON 每次最多展示 2048 个 UTF-16 代码单元，不拆代理对，但可能拆组合字形。
   可以前进、回退、回到开头或输入偏移定位；显示的偏移是 UTF-16，不是字符/字形计数。
   最小变更区间复用既有前 1200 UTF-16 单元内完整字形预览，后文须用原文分页核对。
8. 需要理解分数时，另点“按需解释这对候选”。片段交集/并集保持原分数，出现次数多重集比例
   只解释频率差异；可字面筛选片段、按次数差异排序、逐处/输入序号定位和核对共享覆盖。
   唯一位置片段的顺序链不代表移动、语义或编辑建议。解释位置属于**分析文字**：折叠模式不是原始坐标。
   换左右位置、关闭核对或点“停止并清除片段解释”会取消并丢弃解释，不缓存、不加入报告。
9. “已列候选的文稿对概览”汇总每篇合格/已列位置和文件内文稿伙伴；没有已列位置不证明无重复。
   展开后可按文稿或数量排序。点击“只显示文稿对 d1 / d2”会同时限定候选列表及左右位置选择器；
   近似候选的左右按文字组方向显示，可能是 d2 在左、d1 在右，不会偷偷改为其他文稿。
   一个候选可涉及多对文稿，各对候选数不能相加为全局项数；位置配对数才按实际范围组合计数。
10. 可逐项或对**当前页**手动标记“需要后续检查 / 有意重复”，也可清除标记。
    候选、文稿对与片段清单每页最多 12 项。筛选只改变视图；全局标记、覆盖限制和报告仍包含隐藏项目。
    改普通候选筛选会取消文稿对限定；改文稿对会重置普通候选筛选，并关闭旧原文/片段核对。
11. 手动准备无正文报告，分页查看 JSON，核对尚未审阅数量和全部缺口，再勾选元数据风险确认并下载。
    下载只说明交给浏览器，**不证明已经落盘**。报告为 export-only；没有导入、恢复或批处理应用入口。
12. 换文件、改条件（包括数字输入尚未有效的中间状态）、重新分析或停止会撤销旧候选、标记、解释和报告。
    仅翻页/筛选不改变人工标记。进出本工具使用整页导航；离页或清除会清空，返回不自动重读。
    原文件始终不变。

## 算法与覆盖口径

- 提取 `inspectWriting` 支持的 paragraph/heading/quote/listitem 完整文字。代码、空/短单元跳过；
  图片、标题/摘要字段和图片说明不参与。`units` 是检查到的文字块，不含图片块；`excluded` 为被跳过的文字块。
- 字面模式不规范化任何文字。可选折叠为 `NFKC → toLowerCase → 连续空白变单空格 → trim`；
  不是完整 Unicode case-fold、语言特定大小写、去标点、词干化、翻译或语义分析。
- 规范化后完整字符串相等才进入同文字组；原文与节点序列化分别留存。节点序列化只忽略对象键顺序，
  并不声称原始文件字节相同。可变调用者树不作来源：分析重新校验已拥有的序列化快照。
- 一个组有多个位置时，只按文稿编号计数组合，不物化所有位置对；同篇/跨篇条件用于配对数量及选择器。
  列表“涉及位置/种类”描述整个文字组，部分位置可能在所选范围内没有伙伴，选择器会排除它们。
- 近似按不同文字组建立五个连续代码点片段集合（重复片段只算一次）。交集 / 并集即 Jaccard；
  阈值比较使用整数比例，显示百分比向下保留两位。评分含被候选索引移除的常见片段。
  不同顺序或不同重复次数可以得到 100%；不会因此升格为同文字或自动合并。
- `qualified` 是全部已知同文字组和**已完整评分**达阈值的近似组对，不是全文匹配总数。
  列表优先同文字，近似只在剩余容量保留已评分中的高分；预算不足时不是全局最高/完整结果。
- 报告只对已列出的有限 finding 统计尚未核对数；“全部已标记”不证明所有文字或可能候选都被核对。

## 固定预算及失败方式

既有文件上限仍为单篇 2 MiB / 200 根块 / 12000 节点 / 500000 个文字 UTF-16 单元；
集合 20 篇 / 16 MiB。不放宽原有节点、URL、重复键或检查限制。

| 阶段 | 本轮上限 | 达限行为 |
| --- | --- | --- |
| 来源文字单元 | 4096 | 超限整轮拒绝，不静默截断 |
| 原始文字与可比较类型的规范化文字 | 各 2000000 UTF-16 单元 | 任一超限整轮拒绝，NFKC 膨胀也计入 |
| 近似单组长度 | 4096 代码点 | 超长组仍参加同文字分组，近似明确跳过 |
| 索引片段成员总数 | 200000 | 整组不接纳，不用半个集合评分 |
| 单片段所见文字组数 | 64 | 超过时移除整项，包括早期组，不优待文件顺序 |
| posting 成员对访问 | 250000 | 停止后续候选发现，标注缺口 |
| 唯一候选文字组对 | 12000 | 停止发现，标注缺口 |
| 完整集合比较成员访问 | 1000000 | 剩余候选不评分，没有部分交集假结果 |
| 全局可列 finding | 200 | 同文字优先，近似保留已完整评分中的高分项，标明截限 |
| 按需片段解释 | 每侧 4096 代码点 / 4092 个片段出现位置 | 超长整对拒绝解释，原文分页仍可用；不输出半套交集/频率/顺序诊断 |
| 片段上下文 | 命中前后各 40 代码点 | 位置失效整次拒绝，不回退到邻近位置；覆盖文字分页沿用 2048 UTF-16 上限 |
| 文稿对概览 | 20 篇 / 最多 210 个无序文稿对 / 200 个已列 finding | 只用组合计数，不展开可能数百万个位置对；总配对数与原分析不符整份拒绝 |
| 报告 | 2 MiB UTF-8 | 超限整份拒绝，不截断；重复引用的文字组坐标仅列一次 |

检查器本身达到既有完整性/问题数量限制时也会整轮失败，而非拿不完整提取文字作“无重复”结论。
这些是响应性/内存边界，不是服务器配额，也不承诺任意设备耗时；各阶段定期让出事件循环，可显式停止。

## 隐私、下载与排障

- 正文、规范化文字、索引、节点 JSON、标记及按需片段/筛选词在使用中驻留本页内存；不存 LocalStorage、IDB、
  自动缓存或云端，不上传，不调用保存/发布/恢复/合并接口，不请求来源中的链接或图片。
- 同源恶意脚本、扩展、系统与旁观者仍能看到使用中的内容。清引用不是物理擦除保证。
  不在共享设备留置；保管原稿，不依赖本工具长期保存标记。
- 无正文报告不含正文、标题、摘要、原文件名、URL 或节点，但有来源 SHA-256、本机编号、路径、
  计数和人工标记，仍可能泄露写作模式。文件名固定为 `no-wave-overlap-report-YYYY-MM-DD.json`。
  报告不属于现有密码文件载荷白名单，本轮没有扩张加密工具输入格式。
- “不是有效 UTF-8 / JSON / 摘要不匹配”：重新选择可信原文件，整个来源未采纳，不从坏文件修复部分数据。
- “计算预算 / 检查达到限额”：用集合工具准备更小子集，或提高最短长度后再分析；提高最短长度不能绕过来源总体积保护。
- “没有候选”：先查范围（单篇默认跨篇会无位置对）、最短长度和覆盖缺口；零结果不是没有抄袭/语义重复的证明。
- “已取消 / 报告已失效”：重新手动运行/准备；旧异步结果、旧报告和旧确认不会回填，也没有自动重试。
- 页面不支持 Web Crypto：在支持原生 SHA-256 的可信 HTTPS 环境使用，没有弱摘要回退。
