# 本机双语与平行文稿对照审阅

入口 `/write/parallel`，亦可从写作工作区或本机文稿集合工具进入。无需登录，不需要 API 或网络连接；不是机器翻译或自动润色工具。
设计边界见 [ADR 0051](../architecture/decisions/0051-read-only-local-writing-parallel.md)。

## 明确的手动操作流程

1. **准备来源文稿**：
   使用“本机文稿集合工具”将原稿与译稿（例如中文与英文版，或简体与繁体修订版）打包为集合 JSON（最多 20 篇 / 16 MiB）。
   亦可直接选择单篇备份，但双语对照至少需要两篇文稿构成对照对。
2. **选择来源文件**：
   点击“选择双语对照备份或集合文件”。文件在浏览器本地私有堆内解析并校验 SHA-256。
   页面绝不读取系统目录、账户云端或 URL 查询参数中附带的文件地址。
3. **设置分析条件与阈值**：
   - **对齐范围**：全量结构（默认）、仅正文段落、仅章节标题或仅结构化骨架（标题与引用）。
   - **长短比例预警阈值**：严格（2.5:1）、标准（3.5:1，推荐中英对照）、宽松（5.0:1）。
   - **引用外链对称性检查**：检测两侧段落中包含的外链 URL 是否一致。
4. **审阅文稿对照画像（Profile）**：
   - 查看各文稿对的**结构相似度（Similarity Index）**；
   - 查看**对齐块数**、**左侧单边缺口**与**右侧单边缺口**；
   - 查看段落长度比的**中位数（Median Ratio）**、**中位数绝对偏差（MAD）**与离群分布；
   - 查看各类不对称项（缺口、层级漂移、外链不对称、图片不对称）全局统计。
5. **逐行详细审阅与异常定位（Review）**：
   - 支持按对齐类型（强对齐、部分对齐、左缺口、右缺口）、异常类型和审阅标记多维度筛选；
   - 表格清晰呈现左侧原文片段与右侧平行稿片段；
   - 点击“核对与标记”，打开单行核验面板，查看详细字符统计与外链；
   - 人工标注审阅状态：“有意空缺/保留”或“需后续校对”，标记仅保存在当前会话内存中；
   - 点击“算法解释”，查看动态规划对齐引擎在判定当前行时的具体分值拆解（类型契合分、标题层级分、长短比得分与锚点加分）。
6. **导出无正文脱敏报告**：
   - 勾选“我已知晓报告仅包含脱敏统计与哈希元数据，并授权生成下载”；
   - 点击“下载脱敏对照报告 (JSON)”；
   - 导出的报告仅包含元数据、结构指标、相似度与审阅标记，**绝对不包含任何正文文字或标题内容**。
7. **数据清理与释放**：
   - 点击“清除全部对照内容”重置控制器；
   - 离开页面或切换路由时，浏览器同步清理所有内存引用，返回页面时不自动重读。

## 预算与安全限额

| 检查维度         | 限额 / 规则                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------- |
| 集合文稿数量     | 最多 20 篇文稿                                                                              |
| 文件尺寸上限     | 最多 16 MiB（单篇最多 2 MiB）                                                               |
| 正文字符总量     | 最多 2,000,000 UTF-16 代码单元；超限整轮拒绝                                                |
| 正文结构单元     | 最多 4,096 个块单元                                                                         |
| 对齐计算步数     | 最多 8,000,000 步计算预算                                                                   |
| 对齐网格单元     | 最多 4,000,000 个矩阵单元（DP matrix cells）                                                |
| 不对称异常上限   | 最多 5,000 项 Finding 记录                                                                  |
| 原文片段预览     | 每页上限 2,048 UTF-16 单元；严格不截断代理对                                                |
| 对齐守恒性验证   | 强制检验：$N_{\text{aligned}} + N_{\text{gap}} \equiv N_{\text{total}}$，违背立即整份拒绝   |
| 对齐单调性验证   | 强制检验：对齐坐标严格单调递增，禁止回退                                                    |
| 脱敏报告尺寸上限 | 最多 2 MiB；超限整份拒绝                                                                    |

## 常见问题与排错

- **为什么提示“集合内仅有 1 篇文稿无法构建对照”？**
  双语对照需要原稿与译稿至少两篇文稿。请先在“本机文稿集合工具”将多篇文稿打包为集合文件后再载入。
- **报告中包含我的手稿正文吗？**
  **不包含。** 报告经过强制白名单脱敏，仅导出结构哈希、相似度百分比、段落长度比率分布与您的审阅标记，严禁导出任何原文正文、标题或节点 JSON。
- **页面刷新或关闭后标记会丢失吗？**
  会丢失。为保护未发表手稿隐私，所有数据和审阅标记仅存留于当前页面会话的内存堆中，不写入 localStorage、IndexedDB 或任何服务器。完成审阅后请及时导出脱敏报告。
